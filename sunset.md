# Project Status & Archive
I built Tune-topia with a heavy focus on the Apple Music aesthetic, aiming to create a premium good looking UI while I was learning the ropes of web development.

However, since Monochrome shut down following the Tidal crackdowns, Tune-topia has been heavily impacted. Because this project relied on the same API structures that were hit, the site is currently in a state where it barely works.

## Status: Archived
I am moving this project into an archive state for the following reasons:

- **API Dependency:** Tune-topia utilized the same API pathways as Monochrome. With Tidal's aggressive crackdowns on those sources, the core functionality has been severed.

- **Degraded Experience:** The app is currently hanging by a thread. Metadata fetches are failing and streams are unreliable, which defeats the purpose of the high-end UI I worked to build.

- **Indefinite Pause:** Until I can source a stable, high-quality alternative that matches the project's standards, development is halted.

## Final Note
This repository remains public to showcase the UI design and the work put into the proxy integration. It was a massive learning experience, and I appreciate everyone who followed the progress.

If a viable path forward opens up, I’ll be back. For now, Tune Topia is signing off.
